# Scientific source notices

Ubi-authored contributions use Apache-2.0. Content from scientific sources keeps
its stated CC BY 4.0 terms. Each model archive includes its source citations,
attribution and notices; per-model LICENSE.source files list any additional terms.

Current rights citations are recorded in `source-catalog.json` and each model
version's `SOURCE_REPRODUCTION.json`. Source terms inside OMEX archives are part
of their checksum-pinned provenance.
