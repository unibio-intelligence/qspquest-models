# Pan/Basu 2020 Pediatric Therapeutic Protein PBPK Reduced Validation Model

Source-limited reduced runtime for the Pan/Basu 2020 PK-Sim pediatric therapeutic-protein PBPK paper. It preserves main-paper equations and Tables 2-4 for palivizumab and bevacizumab, but it is not the full 15-organ PK-Sim model.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

3 of 3 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.

DOIs: 10.3389/fphar.2020.00868

## Changes from source

UniBio Intelligence authored the QSPQuest representation, explicit native
execution requests, OMEX packaging, scenario selection and runnable/held status
from the cited scientific source. These additions preserve the declared source
numerical values in the source-coordinate execution profile. They do not
establish physical-unit, population-fitting or complete paper reproduction.
