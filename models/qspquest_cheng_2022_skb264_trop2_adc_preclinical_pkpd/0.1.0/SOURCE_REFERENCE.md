# Cheng 2022 SKB264 TROP2 ADC Preclinical PK/PD Table-Replay Model

Permissive source-complete Cheng 2022 SKB264/sac-TMT TROP2 ADC model. The base model exactly replays public tables and source scalars. A separate exploratory tumor-growth ODE layer fits effective net growth/regression rates to digitized Figure 4/5 tumor-volume trajectories; these rates are not paper NCA, Phoenix, or author PK/PD estimates.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

47 of 47 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.
