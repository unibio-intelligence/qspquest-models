# Efalizumab-driven CD11a turnover

Concentration-driven CD11a target-turnover module using Chetty Table 1 and the stated quasi-steady-state binding approximation. Free, bound and total target are distinct outputs. External constant effect-site concentration is an exploratory input; original Simcyp PK and PASI coupling are unresolved.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

6 of 6 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.
