# Markovic 2024 Vedolizumab Clearance/Remission PopPK

Two-compartment IV vedolizumab PopPK reconstruction from Markovic et al. 2024 Pharmaceutics. The model implements Table 2 fixed-effect parameters, the prior anti-TNF clearance covariate, standard induction/maintenance regimens, AUC accumulation, and paper endpoint overlays for Table 3.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

9 of 9 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.
