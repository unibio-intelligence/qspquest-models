# Briggs 2023 dupilumab AD exposure-response PK/PD

Fixed-effect ODE reconstruction of the Briggs et al. 2023 dupilumab atopic dermatitis population exposure-response model, including SC transit/two-compartment nonlinear PK, EASI indirect response, and IGA latent indirect-response components. Exact table anchors and source-limited paper figure overlays are provided.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

3 of 3 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.

DOIs: 10.1007/s11095-023-03616-8
