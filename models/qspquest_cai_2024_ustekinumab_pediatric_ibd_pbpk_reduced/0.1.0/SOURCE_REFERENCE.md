# Cai 2024 ustekinumab pediatric IBD PBPK reduced FcRn/lymphatic ODE

Source-limited mechanistic reduction of the Cai et al. PK-Sim/MoBi model. It represents SC lymphatic input, central/peripheral distribution, endosomal uptake, FcRn binding/recycling, and catabolism; exactly replays public model constants and endpoint tables; and runs paper-constrained adult/pediatric induction and maintenance ODE scenarios. It is not the unavailable native 15-organ PK-Sim project.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

8 of 8 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.
