# Pernice 2023 GreatNector Alemtuzumab MS Petri Net ODE

Full public-source deterministic ODE expansion of the Pernice et al. 2023 GreatNector multiple-sclerosis alemtuzumab Petri Net. The runtime reconstructs the GreatMod Petri Net places, colored Th1/Th17 transitions, generated C++ rate functions, parameter sets, alemtuzumab pulse events, and source RData trace overlays.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

0 of 5 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.

DOIs: 10.1016/j.jbi.2023.104546
