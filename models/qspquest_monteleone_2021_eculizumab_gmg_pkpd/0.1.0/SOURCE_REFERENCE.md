# Monteleone 2021 Eculizumab gMG PK/PD

Source-limited Monteleone 2021 eculizumab gMG PK/PD model. The paper fixed-effect scenario uses public Table 1 Bayesian mean PK parameters and a reduced free-C5 sigmoid constrained by Figures 2-3. A separate exploratory calibrated scenario uses the reported Table 1 median clearance to better match public Figure 1 peak/trough concentrations.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

7 of 7 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.
