# Asiimwe 2025 ADC MBMA/CUI PopPK

Fixed-effect two-compartment IV ADC PK reconstruction for T-DM1 and T-DXd from Asiimwe et al. 2025. Published CUI endpoints are replayed as static source anchors; dose selection is not executed.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

15 of 15 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.

DOIs: 10.1002/psp4.70013

## Changes from source

from the cited scientific source. These additions preserve the declared source
