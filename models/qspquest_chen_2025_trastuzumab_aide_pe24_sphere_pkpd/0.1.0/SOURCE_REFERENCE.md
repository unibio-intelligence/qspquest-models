# Chen 2025 trastuzumab-PE24 AIDE sphere PK/PD

Public-source ODE reconstruction of the Chen 2025 trastuzumab-PE24 anti-idiotypic distribution-enhancer model, using the recovered 2022 sphere PK/PD equations and 2025 PE24 endpoints.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

1 of 5 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.

DOIs: 10.3390/cancers17091468
