# Quartino 2017 Pertuzumab Neoadjuvant PK/Exposure-Response Model

Source-complete exact-replay and source-limited dynamic model for Quartino et al. 2017 pertuzumab PK and exposure-response in NeoSphere HER2-positive early breast cancer. The runtime preserves the published two-compartment pertuzumab PopPK structure, the logit pCR exposure-response equation context, NeoSphere arm/covariate/pCR counts, target-attainment values, ANOVA/DDI p-values, and dose-selection thresholds.

Source scientific documents and source terms are included in this OMEX archive. Ubi contributions are Apache-2.0; attributed source content retains CC BY 4.0.

7 of 7 source presets are independently matched with the current engine and exposed for standalone simulation. Others remain source-only with explicit holds. This is not population-fitting or clinical qualification.

DOIs: 10.1007/s00280-016-3218-0
